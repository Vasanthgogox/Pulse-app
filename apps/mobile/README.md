# Mobile app (Expo / React Native)

This is the logical home for the Q Mobile app in a future monorepo layout:

- `apps/mobile` – Expo Router app (current code still lives at the repo root and will be moved here when we split into a true monorepo).
- `apps/web` – future web client.
- `packages/shared-types` – shared TypeScript types package.

For now, this folder is a placeholder so the repository layout is ready for containerization / monorepo tooling without disrupting the existing Expo setup.
